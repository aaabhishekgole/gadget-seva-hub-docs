✅ Verified

Before any pickup can be assigned, a field runner must be registered in the admin console's Runner Onboarding tab.

Onboards a new pickup runner through the real admin console

🔗 Same recording as Stage 1

Immediately after onboarding, admin assigns the newly onboarded runner to a pending pickup request — captured in the same continuous take as Stage 1 above.

Assigns the onboarded runner to a request — the SMS/WhatsApp link fires automatically
